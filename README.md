# Env Key Checker

This is a simple Python script that checks your `.env` files against a template `.env.example` file. It will flag any missing keys, which is particularly useful for ensuring your environment variables are correctly set up for your application.

## Usage
1. Place your `.env` and `.env.example` files in the same directory as the script.
2. Run the script using Python:
   ```bash
   python env_key_checker.py
   ```
3. Review the output to see which keys are missing from your `.env` file compared to the `.env.example`.

## Requirements
- Python 3.x
